# PennSIVE.github.io

This is the internal website for PennSIVE tutorials and best practices, built with [Zensical](https://zensical.org/). If you want to make a contribution, please visit the [Contributing](docs/contributing.md) page. 

Pages are pushed to `main` and deployed automatically via the GitHub Actions workflow in [`.github/workflows/docs.yml`](.github/workflows/docs.yml).
